# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Six more open-licensed icons derived from Tabler Icons (MIT): printer, laptop, phone, lock, building, users.
- `remote-access` example.

### Changed
- README rewritten as a step-by-step guide with an icon gallery and embedded examples.

## [0.1.0] - 2026-11-17

### Added
- `build.py`: converts Mermaid flowcharts with `icon:` nodes into Cisco-style SVG, PNG or PDF diagrams.
- Icon set: router, switch, firewall, server, rack, cloud, pc, database, access point.
- Zone boxes (`:::zone-<colour>`), multi-file and folder builds, `--scale`, `--list-icons`, opt-in `--no-sandbox`.
- Three example diagrams and a Typst example.
- MIT licence for code, Apache-2.0 for the derived icons, REUSE-compliant annotations, CI on Linux, macOS and Windows.
